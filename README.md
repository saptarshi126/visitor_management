# Visitor QR Management System

A Python-based visitor management system that generates QR codes
using visitor details such as name, flat number, and contact number.

## Features
- Generates unique QR codes for each visitor
- Stores visitor details locally in CSV
- Automatically opens the generated QR image
- Includes a GUI version for easy use
- Beginner-friendly and lightweight

## Tech Stack
- Python
- qrcode library
- CSV for local storage

## How to Run (Terminal Version)
```bash
python3 app.py
